PROJECT INFORMATION

About The Lab

A simple interactive website designed to make science learning more engaging.

🎯

Project Objective

The main objective of the Virtual Science Lab is to provide students with an interactive environment for learning basic scientific concepts through digital simulations.

The website allows users to perform virtual experiments, change experimental variables, observe calculated results and test their knowledge through a quiz.

💻

Technologies Used

  • HTML5 – Structure of the website
  • CSS3 – Design and responsive layout
  • JavaScript – Interactive experiments
  • Responsive Design – Mobile and desktop compatibility
🔬

Experiments Included

  • ⚡ Ohm's Law
  • 🧪 Acid & Base
  • 🔭 Convex Lens
  • 🔌 Series & Parallel Circuits
🧠

Learning Features

  • Interactive calculations
  • Adjustable experiment variables
  • Instant results
  • Science quiz with score
  • Dark mode
  • Mobile-friendly interface
