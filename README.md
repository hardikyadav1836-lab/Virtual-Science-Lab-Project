# 🔬 Virtual Science Lab

An interactive, web-based laboratory platform designed to make learning science engaging and accessible. This project allows users to simulate science experiments, explore virtual lab interfaces, and test their knowledge using interactive quizzes. 

Developed as an academic project for **B.Sc. IT (First Year)**.

## 🚀 Live Demo
You can view and interact with the live website here:
👉 **https://hardikyadav1836-lab.github.io/Virtual-Science-Lab-Project/**

## ✨ Features
* **Interactive Lab Interface:** A clean visual dashboard for navigating multiple science modules.
* **Simulated Experiments:** Virtual setups to step through practical concepts safely online.
* **Knowledge Assessment:** Integrated quizzes built into the website to test student understanding.
* **Responsive Design:** Optimized to render beautifully on both desktops and mobile devices.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3
* **Logic & Interactivity:** JavaScript (ES6)
* **Hosting:** GitHub Pages

## 📂 Project Structure
* `index.html` - Main landing page / dashboard
* `experiments.html` - Laboratory simulation modules
* `quiz.html` - Interactive quiz interface
* `css/style.css` - Custom styling and layouts
* `js/script.js` - Dynamic interactions and quiz logic
